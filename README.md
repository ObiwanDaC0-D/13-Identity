# 13 — Identity Learning Lab

An interactive, standalone, static educational application exploring identity across sociology, psychology, neuroscience, philosophy, development, and anthropology.

## Features
- 20 curated frameworks with core propositions, mechanisms, examples, cautions and reading references
- Searchable and filterable theory library
- Interactive concept-neighbor map
- Side-by-side framework comparisons
- Eight-question knowledge check
- Private browser-local reflection studio with JSON export
- Four-stage study path, local completion tracking and bookmarks
- Responsive, accessible dark interface

## Run
Open `index.html` in a modern browser. No build step, backend, external libraries, or account is required.

## GitHub Pages
In repository **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save. The expected site URL is `https://obiwandac0-d.github.io/13-Identity/` after deployment.

## Notes
This is an educational archive, not a diagnostic or therapeutic tool. Framework labels indicate orientation rather than formal evidence grading. Sources are introductory reading leads, not exhaustive bibliographic reviews. Reflections and progress are stored in the current browser's localStorage and can be cleared from the app.
